## Adding New Words

To add support for new words:

1. Create an ASL avatar video (MP4/MOV/M4V format)
2. Name the file after the English word: `word.mp4` or `word_phrase.mp4`
3. Add to `ProjectUnmute ProjectUnmute/ProjectUnmute ProjectUnmute/AvatarAssets/`
4. For multi-language support, add translations to `LanguageSettings.swift`

The app will automatically detect and use the new video.
